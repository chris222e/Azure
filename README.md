Azure AI Services Web Application
📌 Descripción

Aplicación web desarrollada con Node.js, HTML y JavaScript que integra diferentes servicios de Azure AI para demostrar capacidades de inteligencia artificial y visión computacional.

🛠️ Tecnologías
HTML
CSS
JavaScript
Node.js
Azure AI Services
Azure OpenAI
🤖 Servicios Implementados
Chat IA
ChatGPT
Detección de Objetos
Extracción de Texto
Generación de Imágenes
Reconocimiento de Objetos Personalizados
OCR (Reconocimiento Óptico de Caracteres)
📂 Estructura
chat.html / chat.js
chatgpt.html / chatgpt.js
deteccion.html / deteccion.js
extraccion.html / extraccion.js
imagen.html / imagen.js
objetos.html / objetos.js
ocr.html / ocr.js
